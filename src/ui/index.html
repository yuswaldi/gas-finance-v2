Phase 1 Scope & Boundaries

This task (FFM-006) is strictly a frontend proof of concept. The following security controls are pending subsequent delivery phases:

  • FFM-007: Server-issued login nonces to protect against token replay attacks.
  • FFM-008: Server-side tokeninfo claim verification (aud, iss, exp, email_verified, sub).
  • FFM-009: Restricting access to registered Google sub allowlisted identities.
  • FFM-010: Cryptographically random server application session tokens (SHA-256 hashed).
  • FFM-011: Session expiration, idle timeout, and explicit revocation.
  • FFM-012: Household context resolution and OWNER / PARTNER authorization.
